바탕화분
다운로드 설치·지우기 자주 묻는 것 변경 내역

설치와 지우기

설치 프로그램은 없어요. 압축을 풀고 바로 실행해요.

윈도우

  1. 압축을 먼저 풀어요. 받은 Hwabun-windows.zip에 마우스 오른쪽 클릭 → “모두 압축 풀기”. 압축 파일 안에서 바로 실행하면 안 돼요.
  2. 푼 폴더를 둘 곳(예: 문서 폴더)으로 옮겨요. 한 번 실행한 뒤에는 옮기지 않는 게 좋아요.
  3. Hwabun.exe를 더블클릭해요.
  4. 파란 “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행을 눌러요. 회사 서명이 없는 개인 프로그램이라 처음 한 번 뜨는 경고예요.
  5. 식물 도감이 열리면 장소 탭(방 창가 · 집 앞 마당 · 옥상 텃밭)에서 식물을 골라 “이거 키우기”. 바탕화면 배경이 바뀌고, 바탕화면에 물뿌리개가 생겨요.

윈도우 11의 “스마트 앱 컨트롤”이 켜진 PC에서는 아예 막힐 수 있어요. 그럴 땐 이 PC에서는 쓰지 못해요(보안 설정을 끄라고 권하지 않아요).

쓰는 법

  • 물 주기: 바탕화면의 물뿌리개를 더블클릭. 하루 한 번.
  • 메뉴: 화면 오른쪽 아래 시계 옆의 새싹 아이콘. 안 보이면 ^ 화살표 안에 있어요.
  • 반려동물: 바탕화면을 3초쯤 보고 있으면(Win+D 또는 바탕화면 클릭) 일어나 돌아다녀요. 그림 속 반려동물을 두 번 클릭 → 밥 주기 · 간식 · 개인기.
  • 아이콘 숨기기: 아이콘을 그림 속 카페트(마당·옥상은 돗자리) 위로 끌어다 놓기. 카페트를 두 번 누르면 다시 나와요. “아이콘 자동 정렬”이 켜져 있어도 돼요.
  • 컴퓨터를 다시 켜면 프로그램은 꺼져 있어요. 물뿌리개를 누르면 같이 켜지고, 메뉴에서 “윈도우 시작 시 자동 실행”을 켤 수도 있어요.

맥

  1. 받은 Hwabun-mac.zip을 열면 나오는 바탕화분 앱을 “응용 프로그램” 폴더로 옮겨요.
  2. 앱을 더블클릭해요. 처음에는 “Apple에서 악성 소프트웨어가 있는지 확인할 수 없기 때문에 열 수 없습니다” (또는 “열 수 없음”) 창이 떠요. 확인(또는 완료)을 누르고 아래 중 하나로 한 번 허락해요.
    • 방법 1 (macOS 14 이하): Finder에서 앱을 오른쪽 클릭(또는 control-클릭) → 열기 → 다시 열기.
    • 방법 2 (macOS 15 이상): 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 “바탕화분이(가) 차단되었습니다” 옆 그래도 열기 → 다시 그래도 열기 → 맥 암호.
    • 방법 3 (그래도 안 되거나 “손상되었기 때문에 열 수 없습니다”가 뜰 때): 터미널에 아래를 붙여 넣고 Enter, 그다음 다시 열기. 
      xattr -dr com.apple.quarantine /Applications/Hwabun.app
  3. 식물을 고르면 배경이 바뀌어요. “바탕화면 폴더에 접근하려고 합니다” 창이 뜨면 허용을 눌러 주세요(바탕화면에 물뿌리개를 만들어요).
  4. 바탕화분은 화면 맨 위 오른쪽, 메뉴 막대의 새싹 아이콘에 있어요(Dock에는 안 보여요).

맥판에는 아직 아이콘 숨기기와 반려동물 놀기(밥·간식·개인기)가 없어요. 데스크탑을 여러 개 쓰면 지금 보고 있는 데스크탑의 배경만 바뀌어요.

지우기

  1. 메뉴(윈도우는 시계 옆, 맥은 메뉴 막대의 새싹) → “완전히 지우기…”를 먼저 눌러요. 원래 배경화면, 숨긴 아이콘, 바탕화면 물뿌리개, 자동 실행, 키우던 기록을 모두 원래대로 돌려 놓고 지워요.
  2. 그다음 프로그램 파일(윈도우는 Hwabun.exe가 든 폴더, 맥은 응용 프로그램의 바탕화분 앱)을 지우면 끝이에요.

순서를 바꿔 프로그램만 먼저 지웠다면, 다시 받아 실행한 뒤 “완전히 지우기”를 누르면 정리돼요. 카페트 밑에 숨긴 아이콘은 지워진 게 아니라 숨김 상태일 뿐이에요(탐색기 “보기”에서 “숨긴 항목”을 켜면 보여요).
