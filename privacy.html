개인정보 처리방침

시행일: 2026년 11월 19일 · 같은 날 문의 방법을 메일로 바꿨어요(4번)

한 줄 요약: 바탕화분 프로그램은 개인정보를 모으지 않아요. 인터넷에 연결하지 않고, 만든이에게 아무것도 보내지 않아요. 메일로 문의할 때만 보낸 분의 메일 주소와 내용을 만든이가 받아요.

1. 모으는 개인정보

프로그램은 모으지 않아요. 회원 가입·로그인이 없고, 이름·이메일·기기 정보·이용 기록을 수집하지 않아요. 분석 도구나 광고도 넣지 않았어요. (메일로 문의할 때 받는 것은 4번을 봐 주세요.)

2. 내 컴퓨터 안에만 저장되는 것

프로그램이 동작하려고 아래 내용을 이용자의 컴퓨터 안에만 저장해요. 만든이는 이 내용을 볼 수 없어요.

  • 키우는 식물과 물 준 날짜, 도감 기록, 꾸미기 설정, 반려동물 설정·친해진 정도
  • 원래 배경화면 설정(되돌리기용 백업)
  • (윈도우판) 카페트 밑에 숨긴 아이콘 목록과 원래 자리
  • 오류가 생겼을 때만 남는 오류 기록(error.log)

저장 위치는 윈도우 %LOCALAPPDATA%\Hwabun\, 맥 ~/Library/Application Support/Hwabun/이에요. 메뉴의 “완전히 지우기”를 누르면 모두 지워져요.

3. 이 페이지와 다운로드

이 페이지와 내려받는 파일은 GitHub(GitHub Pages, GitHub Releases)에서 제공돼요. 페이지를 열거나 파일을 받을 때 GitHub가 접속 기록(IP 주소 등)을 처리할 수 있어요. 이건 GitHub의 방침을 따라요: GitHub 개인정보처리방침. 이 페이지 자체는 쿠키나 방문 분석 도구를 쓰지 않아요.

4. 문의할 때

의견·버그 신고 같은 문의는 메일(ice9863 (골뱅이) gmail.com)로 받아요. 메일을 보내면 보낸 분의 메일 주소, 이름(메일에 적힌 경우), 적은 내용과 붙인 파일을 만든이가 받아요.

  • 답장하고 문제를 고치는 데에만 써요. 다른 사람에게 주거나 다른 곳에 쓰지 않아요.
  • 답장과 수정이 끝나 필요 없어지면 지워요. 지워 달라고 하면 바로 지워요.
