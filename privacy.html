개인정보 처리방침

시행일: 2026년 11월 19일

한 줄 요약: 바탕화분은 개인정보를 모으지 않아요. 프로그램은 인터넷에 연결하지 않고, 만든이에게 아무것도 보내지 않아요.

1. 모으는 개인정보

없어요. 회원 가입·로그인이 없고, 이름·이메일·기기 정보·이용 기록을 수집하지 않아요. 분석 도구나 광고도 넣지 않았어요.

2. 내 컴퓨터 안에만 저장되는 것

프로그램이 동작하려고 아래 내용을 이용자의 컴퓨터 안에만 저장해요. 만든이는 이 내용을 볼 수 없어요.

  • 키우는 식물과 물 준 날짜, 도감 기록, 꾸미기 설정, 반려동물 설정·친해진 정도
  • 원래 배경화면 설정(되돌리기용 백업)
  • (윈도우판) 카페트 밑에 숨긴 아이콘 목록과 원래 자리
  • 오류가 생겼을 때만 남는 오류 기록(error.log)

저장 위치는 윈도우 %LOCALAPPDATA%\Hwabun\, 맥 ~/Library/Application Support/Hwabun/이에요. 메뉴의 “완전히 지우기”를 누르면 모두 지워져요.

3. 이 페이지와 다운로드

이 페이지와 내려받는 파일은 GitHub(GitHub Pages, GitHub Releases)에서 제공돼요. 페이지를 열거나 파일을 받을 때 GitHub가 접속 기록(IP 주소 등)을 처리할 수 있어요. 이건 GitHub의 방침을 따라요: GitHub 개인정보처리방침. 이 페이지 자체는 쿠키나 방문 분석 도구를 쓰지 않아요.

4. 문의할 때

문의는 GitHub 이슈로 받아요. 이슈에 쓴 글과 GitHub 계정 이름은 누구나 볼 수 있어요. 이름·연락처·주소 같은 개인 정보는 적지 말아 주세요. 오류 기록을 붙일 때도 개인 정보가 들어 있지 않은지 확인해 주세요.

5. 어린이

개인정보를 모으지 않으므로 나이에 따라 따로 받는 동의는 없어요. GitHub 이슈를 쓰려면 GitHub의 이용 연령 기준을 따라야 해요.

6. 바뀔 때

나중에 인터넷을 쓰는 기능을 넣는 등 이 방침이 바뀌면, 바뀐 내용을 이 페이지에 먼저 알리고 시행해요. 그런 기능은 이용자가 직접 켜야만 동작하게 할 거예요.
